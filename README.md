# Namemanbha Dkhar — Portfolio

A responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser.

## Customize
- Replace `your.email@example.com` in `index.html`.
- Replace the GitHub and LinkedIn links.
- Change project links from `href="#"` to real repositories.
- Add a profile photo by replacing the `ND` avatar block if desired.
